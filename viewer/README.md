# Квартира — интерактивная 3D-модель

Вьюер квартиры на three.js: реальная геометрия из 3D-модели (`apartment_from_fbx.blend` / `5_2.fbx`), упрощённая до «блок-аута» — без текстур и мелких деталей, только стены, пол и мебель.

## Запуск

```bash
cd viewer
./start.sh          # или: python3 -m http.server 5173
```

Открыть <http://localhost:5173>.

Модули и GLB грузятся по HTTP, поэтому открывать `index.html` напрямую через `file://` нельзя.

## Управление

| Действие | Как |
| --- | --- |
| Вращение | ЛКМ + перетаскивание (или один палец) |
| Масштаб | Колесо мыши / щипок |
| Сдвиг | ПКМ + перетаскивание |
| Изометрия / Сверху | кнопки справа сверху (или клавиши `1` / `2`) |
| Прозрачные стены | кнопка «Стены» (`3`) |
| Автовращение | кнопка «Вращение» (`4`) |
| Выбрать объект | клик по объекту — id печатается в консоль, объект подсвечивается |
| Снять выделение | клик по пустому месту или `Esc` |

## Структура

```
viewer/
  index.html          — страница и HUD
  src/main.js         — сцена, свет, камера, загрузка GLB, UI
  src/style.css       — оформление HUD
  public/apartment.glb— упрощённая модель (Draco, ~5.5 МБ)
  public/apartment.objects.json — список объектов: id, размер, центр, число полигонов
  vendor/             — three.js r186 + OrbitControls, GLTFLoader, DRACOLoader, RoomEnvironment
  tools/export_glb.py — скрипт пересборки GLB из Blender
```

## Выбор объектов

Клик по объекту подсвечивает его (оранжевый контур + подсветка материала) и печатает в консоль браузера:

```
[selected] askona_elisa_grand_linens_00
  size:   2.10 × 0.60 × 1.80 м
  center: (3.42, 0.31, -1.24)
  tris:   18342
SELECTED_ID=askona_elisa_grand_linens_00
```

`SELECTED_ID` — имя объекта в Blender; по нему объект можно убрать/заменить в `tools/export_glb.py`. Крупные объекты (мебель, стены, окна, пол) экспортируются отдельными мешами и выбираются поштучно. Мелкие предметы (декор, посуда, фурнитура — короче 0.3 м) склеены в группы `Apt_small_*`, клик по ним выбирает всю группу (маркер в точке клика).

three.js немного чистит имена при загрузке: пробелы заменяются на `_`, а символы `. : / [ ]` удаляются. Поэтому стены (`Layer:0.013`) в консоли называются `Layer0013`, а пол — `ApartmentFloor`.

В консоли также доступны:

```js
__viewer.listObjects()        // все id
__viewer.selectById('Box001') // выбрать объект по id
__viewer.selection            // текущий выбор
__viewer.deselect()
```

## Как собрана модель

`tools/export_glb.py` запускается в Blender в фоне:

```bash
blender -b ../blender_test/apartment_from_fbx.blend --python tools/export_glb.py
```

Что делает скрипт:

1. Отбирает объекты квартиры по координатам (отсекает соседние квартиры и этажи).
2. Применяет все трансформации объектов (иначе после join геометрия «разъезжается»).
3. Считает средний цвет текстуры каждого материала и присваивает объекту один плоский цвет.
4. Оставляет крупные объекты (от 0.3 м) отдельными мешами с исходными именами — это id для выбора; мелкие склеивает в ~26 цветовых групп `Apt_small_*`.
5. Упрощает тяжёлые меши (Decimate, до 900 полигонов на объект).
6. Экспортирует GLB с Draco-сжатием и пишет `apartment.objects.json`.

Стены (`Layer:0.013`) и пол (`ApartmentFloor`) вынесены в отдельные меши — поэтому в вьюере работает режим прозрачных стен.
