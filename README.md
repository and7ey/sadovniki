# Квартира — интерактивная 3D-модель

Blockout-визуализация квартиры в браузере (three.js): изометрический и верхний вид,
cutaway стен, выбор объектов кликом, зеркала с реальным отражением, светильники-
подвесы с включением по клику.

**Демо:** https://and7ey.github.io/sadovniki/

## Что внутри

```
viewer/
  index.html            статическая страница (import map -> vendor/three)
  src/main.js           сцена, камера, свет, зеркала, светильники, выбор объектов
  src/style.css         HUD
  vendor/               three.js + addons + draco (локально, без CDN)
  public/apartment.glb  готовая модель (Draco), ~8 МБ
  public/apartment.objects.json  манифест мешей (id, габариты, полигоны)
  tools/export_glb.py            Blender-пайплайн: чистка сцены, материалы, экспорт
  tools/make_floor_herringbone.py генератор текстуры пола «ёлочка» 600×125 мм
floor.jpeg               исходная фотография плитки кварцвинила (только как текстура)
```

## Модель

* Плоские цвета, без текстур на мебели — намеренный blockout.
* Пол — настоящая ёлочка: планки 600 × 125 мм, рисунок сгенерирован геометрически
  (не тайлинг фото) и растянут на всю квартиру одним атласом 4096 px, поэтому
  повторений нет. Рисунок уложен под 45° против часовой стрелки
  (`ROTATE_DEG` в `tools/make_floor_herringbone.py`).
* Керамогранит 120 × 60 см — отдельная геометрия в санузле, санузле-гостевом и
  холле (`Tile_hall`, `Tile_wc`, `Tile_bath`, `Tile_wall_bath`), текстура
  `tools/tile_white.jpg`.
* Шторы (Plane003/007/1196/1197/1202) — ткань Velvet Lux 10 (Союз-М), оливково-
  зелёный `#6C7A52`.
* Подвесы `Four_Pendant_Lights_..._008/009/010` — клик включает/выключает лампу
  накаливания 60 Вт (2700 K). В выключенном состоянии абажур матово-белый;
  светильники не выбираются как объекты. Лампочка визуально внутри абажура, а
  сам абажур тени не отбрасывает — иначе он запирал бы свет и комната оставалась
  тёмной; стены по-прежнему свет не пропускают.
* Подвесы над столом `Maryland2` (4 абажура с подвесами и арматурой) возвращены
  в сцену: их отсекал фильтр мелких объектов при экспорте, теперь для них есть
  исключение (`KEEP_ZONES` в `viewer/tools/export_glb.py`).
* Стены (`Layer0013`, `Object001`) при загрузке режутся на отдельные плоские
  поверхности — «Стена 01», «Стена 02», … (139 штук). Каждую стену можно выбрать
  кликом отдельно и позже покрасить: у каждой поверхности свой материал.
  На телефоне (лёгкий профиль) стены остаются одним мешем — там выбор не нужен.
* Свет подвесов отбрасывает тени: стены и матовое стекло его не пропускают.
* Зеркала отражают сцену (CubeCamera), стекло и матовое стекло полупрозрачные.
* Два пресета освещения: ночной (по умолчанию) и дневной — тот, что был раньше.
  Кнопка «День»/«Ночь» рядом с «Изометрией» (клавиша `5`) переключает их вместе
  с фоном и темой интерфейса.
* Цоколь убран: под квартирой сразу тонкая плита-пол, вырезанная по реальному
  контуру пола (`ApartmentFloor`), поэтому за стены не выступает.
* Стены покрашены в цвета Caparol: mai 45 (зелёный) — Стена 33 и Стена 117,
  palazzo 205 (оранжевый) — Стена 35 и Стена 83, marill 30 (бежевый) — Стена 101,
  106, 107, 109, 115, 36, 58, 84 и панель `Line013`. Краска наносится по центру
  каждой поверхности, поэтому индексы стен можно менять без потери цветов
  (таблица `WALL_PAINT` в `viewer/src/main.js`).
* Зеркала прихожей (`Box2131642377` + `Box2131642378`) объединены в одно полотно
  `MirrorHall` — шва между двумя створками больше нет.
* Временные кнопки освещения (справа в HUD): «Лента зал», «Лента дет», «Треки
  зал», «Треки дет». Ленты — тёплые точки вдоль верха стен (Стена 114/138/129 в
  гостиной, Стена 51 в детской), сами ленты не рисуются, только свечение. Треки —
  прямоугольные шинопроводы 2890 × 2000 и 2000 × 2190 мм с четырьмя лампами GU10
  на 640 лм каждая (тени не отбрасывают). На телефоне реальные источники для
  лент и треков не создаются — остаются только сами светильники.
* Входная дверь (белая, с ручкой и коробкой) — в стене холла.
* Пол холла подрезан по контуру квартиры, за стены не выступает.

## Мобильный режим

На телефонах включается облегчённый профиль (`?low=1` — принудительно,
`?high=1` — отключить): без сглаживания, pixel ratio ≤ 1.25, тени полностью
выключены, без карты окружения, зеркала — простые глянцевые панели без
отражений, текстуры не больше 1024 px. Это в разы меньше видеопамяти и
draw call'ов на кадр — иначе Android-браузер теряет WebGL-контекст и квартира
пропадает.

Если контекст всё же потерян, страница один раз сама перезагружается в
облегчённом профиле (счётчик в `sessionStorage`, поэтому цикла перезагрузок
нет); при повторной потере показывает сообщение и кнопку «Перезагрузить».

## Погода в шапке

Виджет «Облачно · 8 °C» — заглушка, которую наполняет Home Assistant:

```js
window.setApartmentWeather({ temp: 8, state: 'Облачно', icon: 'cloudy' });
// или postMessage: { type: 'apartment-weather', payload: { temp, state, icon } }
```

`icon`: `cloudy | partly | sunny | rain | snow | storm | fog` (можно не передавать —
иконка подберётся по тексту `state`). Значение температуры — число или строка.

## Пересборка модели

Нужен Blender 5.x и исходная сцена (`blender_test/apartment_from_fbx.blend`,
в репозиторий не входит — слишком большая).

```bash
# 1. текстура пола (нужен floor.jpeg в корне)
blender --background --python viewer/tools/make_floor_herringbone.py

# 2. экспорт GLB
blender -b blender_test/apartment_from_fbx.blend --python viewer/tools/export_glb.py
```

`export_glb.py` содержит все правки сцены: удалённые объекты, клиппинг, зеркала,
перекраски, масштаб камина, материалы пола/штор/светильников.

### Синхронизация с 5_3_blender.fbx

Сцена `blender_test/apartment_from_fbx.blend` приведена в соответствие с
`5_3_blender.fbx`: из неё удалены 1616 объектов, которых нет в 5_3 (декор, растения,
посуда, рейлинги, плинтусные накладки, ТВ-панель и т. п.). Список — в
`blender_test/deleted_in_53.json`, резервная копия сцены до удаления —
`blender_test/backup/apartment_from_fbx_20261022.blend` (md5 `b2e5dcf0…1333`).
Обе сцены сверены по облаку точек с допуском 5 см: 90 % поверхности совпадает
в обе стороны, структурные объекты (стены, пол, стекло, зеркала, светильники,
шторы) не затронуты.

## Публикация

```bash
./tools/deploy_pages.sh     # выкладывает viewer/ на GitHub Pages (ветка gh-pages)
```

Основная ветка `main`/`master` — исходники и Blender-пайплайн; сайт собирается
из содержимого `viewer/` в корне ветки `gh-pages`.
