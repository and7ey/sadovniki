# Квартира — интерактивная 3D-модель

Blockout-визуализация квартиры в браузере (three.js): изометрический и верхний вид,
cutaway стен, выбор объектов кликом, зеркала с реальным отражением, светильники-
подвесы с включением по клику.

**Демо:** https://and7ey.github.io/sadovniki/

## Что внутри

```
viewer/
  index.html            статическая страница (import map -> vendor/three)
  src/main.js           сцена, камера, свет, зеркала, светильники, выбор объектов
  src/style.css         HUD
  vendor/               three.js + addons + draco (локально, без CDN)
  public/apartment.glb  готовая модель (Draco), ~11 МБ
  public/apartment.objects.json  манифест мешей (id, габариты, полигоны)
  tools/export_glb.py            Blender-пайплайн: чистка сцены, материалы, экспорт
  tools/make_floor_herringbone.py генератор текстуры пола «ёлочка» 600×125 мм
floor.jpeg               исходная фотография плитки кварцвинила (только как текстура)
```

## Модель

* Плоские цвета, без текстур на мебели — намеренный blockout.
* Пол — настоящая ёлочка: планки 600 × 125 мм, рисунок сгенерирован геометрически
  (не тайлинг фото) и растянут на всю квартиру одним атласом 4096 px, поэтому
  повторений нет.
* Шторы (Plane003/007/1196/1197/1202) — ткань Velvet Lux 10 (Союз-М), оливково-
  зелёный `#6C7A52`.
* Подвесы `Four_Pendant_Lights_..._008/009/010` — клик включает/выключает лампу
  накаливания 60 Вт (2700 K). В выключенном состоянии абажур матово-белый;
  светильники не выбираются как объекты.
* Свет подвесов отбрасывает тени: стены и матовое стекло его не пропускают.
* Зеркала отражают сцену (CubeCamera), стекло и матовое стекло полупрозрачные.

## Локальный запуск

```bash
cd viewer
python3 -m http.server 5173
# http://localhost:5173/
```

## Пересборка модели

Нужен Blender 5.x и исходная сцена (`blender_test/apartment_from_fbx.blend`,
в репозиторий не входит — слишком большая).

```bash
# 1. текстура пола (нужен floor.jpeg в корне)
blender --background --python viewer/tools/make_floor_herringbone.py

# 2. экспорт GLB
blender -b blender_test/apartment_from_fbx.blend --python viewer/tools/export_glb.py
```

`export_glb.py` содержит все правки сцены: удалённые объекты, клиппинг, зеркала,
перекраски, масштаб камина, материалы пола/штор/светильников.

## Публикация

```bash
./tools/deploy_pages.sh     # выкладывает viewer/ на GitHub Pages (ветка gh-pages)
```

Основная ветка `main`/`master` — исходники и Blender-пайплайн; сайт собирается
из содержимого `viewer/` в корне ветки `gh-pages`.
